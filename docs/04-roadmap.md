# Roadmap

## Phase 1: Projektgrundlage

- Zusammenarbeit und Regeln dokumentieren.
- Anforderungen und offene Fragen sammeln.
- Infrastruktur-Optionen bewerten.
- Domain-/Hosting-Entscheidung vorbereiten.

## Phase 2: Technisches Fundament

- [x] Astro und statischen Build festlegen.
- [x] Komponentenorientierte Projektstruktur erstellen.
- [x] Validiertes YAML-Inhaltsmodell definieren.
- [x] Lokalen Entwicklungsserver einrichten.
- [x] Ersten deploybaren Build herstellen.

## Phase 3: Informationsarchitektur

- Seitenstruktur festlegen.
- Navigationsmodell fuer Mobile und Desktop definieren.
- Inhaltsmodule fuer Ablauf, FAQ, Orte und Geschichte modellieren.
- Platzhalterinhalte mit realer Struktur einbauen.

## Phase 4: Komponenten

- [x] Startbereich als Komponente migrieren.
- [x] Ablauf-Komponente migrieren.
- [x] FAQ-Komponente migrieren.
- [x] Location-/Anfahrt-Komponente migrieren.
- Story-/Timeline-Komponente bauen.
- Footer und optionale Zusatzlinks vorbereiten.

## Phase 5: Designintegration

- Finales Design analysieren.
- Tokens und Theme anpassen.
- Layout, Typografie, Farben und Bildsprache umsetzen.
- Responsive Details fuer Smartphone und Rechner verfeinern.

## Phase 6: Veroeffentlichung

- Letzte offene Pruefpunkte klaeren.
- Build validieren.
- Preview bereitstellen.
- Custom Domain anbinden.
- QR-Code mit finaler URL erzeugen und testen.

## Phase 7: Pflege und Abschluss

- Inhaltliche Korrekturschleifen.
- Finale Performance- und Mobile-Pruefung.
- Go-live.
- Entscheidung zur Archivierung nach der Hochzeit.
